# Customer Segmentation Project

## Project Overview

This project focuses on customer segmentation using demographic and purchasing data. The objective is to group customers into different segments based on their purchase behavior and characteristics such as age, gender, and income.

## Objectives

* Analyze customer demographics and purchase behavior.
* Segment customers into High Value, Medium Value, and Low Value groups.
* Visualize customer segments using Power BI.
* Generate business insights for targeted marketing strategies.

## Tools Used

* Microsoft Excel
* CSV Dataset
* Power BI Desktop

## Dataset Attributes

* CustomerID
* Age
* Gender
* Income
* PurchaseAmount
* Customer Segment

## Methodology

### 1. Data Collection

Customer data was created and stored in a CSV file containing demographic and purchase information.

### 2. Data Import

The dataset was imported into Power BI using the Text/CSV connector.

### 3. Customer Segmentation

Customers were classified into segments based on their purchase amount:

* High Value: Purchase Amount > 12000
* Medium Value: Purchase Amount > 5000 and ≤ 12000
* Low Value: Purchase Amount ≤ 5000

### 4. Data Visualization

The following visualizations were created:

* Total Customers (Card)
* Average Purchase Amount (Card)
* Customer Segment Distribution (Pie Chart)
* Purchase Amount by Segment (Bar Chart)
* Gender Distribution (Pie Chart)
* Interactive Filters (Slicers)

## Key Features

* Customer segmentation based on purchasing behavior.
* Demographic analysis using age and gender.
* Interactive dashboard with filters.
* Identification of high-value customers.
* Business insight generation through visual analytics.

## Results

The dashboard successfully categorized customers into different segments and provided insights into customer spending patterns. High-value customers were identified, and demographic trends were analyzed to support data-driven business decisions.
